This doc covers the fit-cli repo itself.
This is a human-written doc.  Targeted, specific, reviewed LLM edits are permitted; but keep this doc concise and accurate.

The repo is public, and in `couchbaselabs` org.
It's public because it at least simplifies and possibly allows GHAs in other repos from other orgs like `couchbase` to call it.
It also allows the installation line `curl -fsSL https://raw.githubusercontent.com/couchbaselabs/fit-cli/main/install.sh` to work simply and without auth.

There _might_ be possible workarounds for the above, but so far public access has kept things simple and not caused issues.
